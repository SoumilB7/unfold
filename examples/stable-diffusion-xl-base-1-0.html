Initial noise
z_T: random Gaussian latent, shape [4 channels], sampled in the VAE latent space. (Image-to-image instead starts from an encoded input image.) This is the latent the loop iteratively denoises.
Timestep
The current step's noise level t (decreasing T -> 0). Embedded, then projected and added inside every ResNet block (and the mid block) — a U-net conditions on the noise level additively, not through AdaLN. SDXL also adds a micro-conditioning embedding — the pooled text vector together with the image size / crop / target-size ('time_ids') embeddings, projected from 2,816-d — to this timestep embedding (addition_embed_type = text_time).
Text prompt
The conditioning prompt, encoded by 2 text encoders (CLIP (768-d), CLIP (1,280-d)). Their token features are concatenated along the feature axis (768 + 1,280 = 2,048-d) into the cross-attention conditioning.
CLIP (768-d) text encoder

Latent state (z_t)
The working latent — a single slot the loop reads and rewrites each step. It is seeded once from the initial noise (z_T), overwritten every step by the scheduler's output (z_{t-1}), and read by the denoiser as the current z_t. 'z_t' and 'z_{t-1}' are this same slot at consecutive steps, not separate tensors — the two arrows feeding it are two writers at different times, not a sum.
4 channels
U-Net denoiser
The network applied at every step: a 3-stage convolutional U-net (down → mid → up with skip connections) that takes the latent z_t (+ timestep + text conditioning) and predicts the noise. Each down stage halves the spatial resolution (the latent is 4× downscaled at the bottleneck) and each up stage doubles it back; the timestep modulates every ResNet, and text conditioning (dim 2048) enters the cross-attention stages. Scheduler — Euler
Euler combines the denoiser's prediction with z_t to produce z_{t-1}, one step toward a clean latent. The loop repeats for N sampling steps (N chosen at inference, typically ~20-50 — it is not a config field).

Concatenate (feature axis)
The encoders' per-token features are joined along the feature (channel) axis — stacked side by side into wider tokens, with no projection, no mixing and no added parameters. Here 768 + 1,280 = 2,048. That combined tensor is the keys/values every cross-attention stage reads. It is the same operation (torch.cat over the feature axis) as the U-net's skip connections — which is why both use the ‖ connector, not ⊕.

⊕ Timestep embedding
The linear-projected timestep embedding is added here (ResnetBlock2D: hidden_states = hidden_states + time_emb_proj(SiLU(temb))).
