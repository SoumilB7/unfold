# S7 final cross-platform closure poisons

The permanent gates cover the exact defects found by Linux:

- relocating an identical source closure preserves its portable seal;
- changing source bytes, logical location, component ownership, external
  provenance, or source multiplicity changes that seal;
- fact spans persist as content hash + line and never as an installation path;
- an exact path wins over duplicate basenames;
- a missing or conflicting static source address blocks generation;
- a supporting static source absent from the runtime instance still resolves
  through `ProgramIndex`;
- a KV source-layer index cannot shadow the `ProgramIndex` source census;
- moving the same execution observation across hosts preserves its relation-plan
  identity, while changing an execution call changes it;
- the committed 29+10 artifacts must match a live Linux regeneration inside the
  OS network namespace.

These are producer poisons.  No model name, family table, field convention, or
blanket semantic-normalization rule is used.
