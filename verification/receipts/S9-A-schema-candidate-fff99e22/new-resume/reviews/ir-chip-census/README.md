# Frozen26 IR and chip census; bounded coverage correction

Scope: pure JSON/gzip/HTML and source inspection of all 39 completed captures from frozen26. No model, test, project-module or browser execution; no output blessing. `summary.json` has per-target totals. Each target report pins the exact saved before/after IR and HTML input bytes. `finite-triage.json` retains every newly scoped typed-null address and all 18 explicit-marker schema patterns, with per-model counts. The executable audit scripts import only the Python standard library.

## What the saved pages prove

- The finite census policy at frozen26 identified 14,343 scalar unknown paths and 8,459 unresolved architectural envelope paths: 22,802 serialized annotation paths. Every path was present in the actual saved HTML unknown-value report, with zero unexpected paths. All finite-policy metadata checks passed. The 89 unresolved fact rows carried reason metadata. There were zero serialized class-3 records, so no class-3 claim is being authenticated by this data review.
- All 39 pages contain four pairwise distinct chip CSS rules. Unresolved uses green/dashed; class_default blue/solid; symbolic purple/double; pending_design amber/dotted. The ordinary captures contain one typed class_default declaration and one actual card emission, on SDXL. The latter is inside the compressed/lazy card payload; this audit decodes and verifies that payload rather than mistaking absence from inline markup for an absent chip. No ordinary corpus input emitted a typed unresolved, pending_design or symbolic card chip. Unknown-value report annotations are separate from typed card-chip declarations.
- The source census derives pending_design obligations separately from drawn-fact events and construction occurrences. A chip cannot create a drawing receipt or inflate the occurrence denominator. Pending-design references must already be complete and qualified. This is a source finding; the saved captures contain no live census/chip-event trace to replay.

The capture is a transport artifact, not a retained live authority object. It cannot authenticate runtime object aliases, reader-issued investigation tokens, actual browser click success, or a visual design verdict. These remain root-owned runtime/independent-review obligations. The audit does not prove the unresolved mechanisms or claim S9-A is complete.

## Correction and earliest shared boundary

Only `model_unfolder/presentation.py` and `tests/test_s9_finite_unknown_coverage.py` change. The shared schema iterator was the earliest missing boundary: producer attachment, renderer annotations and the consistency census already consume it. Adding new evidence claims or separate producer exceptions would duplicate authority.

The architectural iterator now includes the exact opaque fallback slot (and its declared child blocks). The scalar iterator retains the existing root policy/order and reuses it only for declared typed block attention/FFN snapshots and submodel groups, including their declared nested `sub_models`. It covers canonical modality pipeline operation and fusion operation/target literals. The traversal does not scan arbitrary mappings, prose, raw config or `source_evidence`; unsupported metadata cannot become an architectural unknown by spelling alone. Cyclic nested submodels fail explicitly.

Existing attachment supplies `investigation_missing / unknown_reason_unrecorded` with no investigation record. It leaves semantic values, graph connectivity, node IDs, occurrence identities, citations and proof objects alone. Class 3 is neither introduced nor inferred. The visible delta is the existing collapsed unknown-reason report and opaque-block metadata, subject to the normal output enumeration/review rule; no output is blessed here.

Focused controls cover active/dormant opaque omission, own-address typed drills and nested towers, conditional null policy, modality stage/fusion omission, diagnostic/arbitrary-string exclusion, omitted annotations, changed values, and explicit schema-cycle rejection. The renderer report must emit the exact paths while producing no graph or typed-chip events. Source was syntax-inspected only; root must run the new file plus existing presentation/authority lanes, regenerate actual pages and enumerate output deltas.

Source and test growth are in `handoff.json`; exact copies and unified diff are held alongside it. The independent reviewer must inspect those exact hashes. No project runtime was executed by this subagent.
