## Qualification and replay ownership

The renderer replay does not treat serialized claim-kind labels as a new proof. Its separate pinned summary-source replay reconstructs the existing root/stage readers and three actual proof classes from each exact saved inventory/config and source bundle; validates the requested factory/config hash; matches static/runtime root hashes; maps preserved scratch sources for the changed/rewrite/unchanged conditions; requires the three freshly derived values to equal that case's saved facts; and calls the actual ConstructionSummary producer/reverse validator. It records that no model/recipe executed. This is a new bounded static proof replay over historical construction evidence, not a new construction run.

The rendering phase checks each proof receipt against that exact case's facts/input/inventory hashes and unchanged production source pins. Summary quantities/citations are recomputed from the three proved values, and shape/population addresses agree. Independently, all11 proof-result pins and archived source bytes were checked, including every root/external source required by the recorded index. A proof receipt from another case cannot merely supply matching display strings while bypassing these pinned inputs.

The old/new pure projector comparisons use the same saved values and deliberately empty outer handoffs. These simple value wrappers do not qualify new facts and produce no ConstructionSummary themselves. Their bounded purpose is to identify the label/metadata/component-entry migration. Normalized equality is followed by exact per-field transport into the saved complete IR and a reverse comparison of that entire IR. Thus the empty-handoff probe does not replace or truncate the complete pipeline, and unrelated components/facts/warnings are preserved. Summary is supplied from the separately validated proof receipt, not guessed by the simple wrappers.

`render-input-identity.json` additionally records that every actual render input is the saved final IR plus the unchanged parameter-display record.
