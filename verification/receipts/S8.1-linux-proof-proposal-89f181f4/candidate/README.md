Eight-file overlay only: six production files, one deliberately updated existing expectation, and one new control module. The repository is unchanged. No tests, models or artifact regeneration ran during preparation. Source parsing and old/new hash/diff generation were the only Python operations.

All ten `ClaimProofSummary.index_fingerprints` producers now call the existing `portable_source_index_fingerprint`: six UNet claim variants, cell connections, primary ports, constructor defaults and generic constructor existence. Local `ProgramIndex.fingerprint`, address equality, indexed-object membership, checkpoint validation and independent proof derivation are untouched.

The original portable calculation is extracted without changing its computation AST. It retains the full source multiset, parse-failure sources, shortest unique trailing locators, content fingerprints, ownership and external provenance. A per-instance cached property stores the derived digest only for exact immutable tuple/frozen-source/scalar shapes. `ProgramIndex` currently accepts mutable source-node lists without validation, so those retain the original uncached behavior. Errors are not cached. The memo is absent from dataclass fields, equality, asdict, pickle, deepcopy, shallow copy and replace transport. No global cache or raw-fingerprint keyed reuse exists.

`tests/test_portable_claim_summary.py` constructs actual tiny source indexes and reconciled runtime DTOs, obtains real constructor-default facts and serializes their full `ProjectionFactCitation.summary`. Relocation equality, changed source bytes, ownership and external provenance, post-qualification checkpoint mutation, generic indexed-object membership, same raw-fingerprint collision, memo computation count, copy/serialization/reset and mutable/error controls are covered. These are unrun source controls, not claimed results. The existing S7 constructor expectation intentionally changes only the expected persisted index seal.

The generic constructor's existing absolute-path `evidence_refs` are separately scoped: they remain unchanged, and the new test explicitly does not claim whole generic-summary relocation equality. Current observed Linux failures concern the SDXL persisted index fields. The candidate changes no S7 artifact, matrix source stamp, preservation normalizer, or expected output.
