# Stale and historical documents

Nothing in this directory is an implementation authority or current product
roadmap.

These files are retained only so prior reasoning and problem evidence are not
destroyed. Before reusing any claim:

1. restate it as a mechanism rather than a model/session story;
2. verify it against the current working tree;
3. compare it with `../07-current-state/`;
4. promote only the durable law or still-open delta into the appropriate
   operational chapter;
5. never copy an old completion status, test count, line number, or family
   workaround into current plans.

Return to the [authoritative documentation index](../README.md).
