config value resolution, source observation, architecture interpretation, IR

## 3. Why things happened

Six real defects were found and fixed at shared boundaries, none with a model
branch:

1. `CallArgumentBinding` required an imported child class to share the root
   wrapper's file; exact occurrences lawfully cross files (U10-B).
2. The parser shadow hook leaked a strict reader's rejection as an exception
   for source-less roots; converted to the typed `missing_source` failure
   (U10-C).
3. D0 refused to guess config paths for Diffusers' many scalar constructor
   parameters — correct — until the `register_to_config` *execution protocol*
   was recognised as an exact import (not a spelling) (U10-F2).
4. Lumina reuses one block class at three construction sites, each activating
   one of two guarded attention calls; class-wide guarded calls were being
   read as runtime lane cardinality (U10-F3).
5. The shared renderer briefly made every secondary input static, which
   would have hidden MusicGen's real external-K/V card and legitimate ALiBi
   drills; fixed with a symmetric card-driven rule (U10-F3).
6. Honest labels exposed a pre-existing box-sizing bug (BLOOM's FFN label had
   always overflowed); the layout rule now grows boxes to fit (U10-F3).

All are general. The receipts also record a correct refusal: "framework
defaults are not source absence" — a minimal AuraFlow config still resolves
4+32 layers because the installed constructor supplies registered defaults,
while a genuinely uninstalled transformer stays opaque.

### Experiment A (2026-08-31) — refinement of the cause
The blank/opaque outcome has **two** causes. Import closure explains PixArt,
SD3.5, Mochi and the external-`Attention` witnesses (CogVideoX, Qwen-Image,
HunyuanVideo, Lumina, AuraFlow). FLUX.1/FLUX.2/Wan/LTX/PRX keep their attention
class **in their own file** and fail because `diffusion_block.py:299-310`
refuses every `source_mixin_delegate` lane by design. The decisive counter-
example: the identical `BasicTransformerBlock` PixArt leaves blank is fully
drawn inside SDXL through the UNet readers' closure. Closure alone brings SD3.5's
×38 skeleton back but its cells stay `materialization_blocked` (joint dual-state
lane, heterogeneous `FeedForward.net`, merged-index `Attention` needing
`canonical_import`); PixArt additionally needs the config-guard selector for its
three guarded `transformer_blocks` init branches. Measured: **37/111 ≈ 33 %** of
source-provable denoiser facts proven (PixArt 0/9, SD3.5 0/7). The blanket
`_DIFFUSION_SOURCE_CLOSURE_PATHS` excusal already lets every net pass on a blank
denoiser today.

## 7. Verdict

**Execution: A. Outcome against the goal: C.** Every law U10 wrote for itself
was followed, the funnel was genuinely dismantled, and the receipts are the
most rigorous in the campaign. But the unit reproduced the DeepSeek/GLM
"lost-detail" episode at corpus scale: a self-imposed index boundary was
treated as an epistemic unknown, verified skeletons of two flagship models
were replaced by blank boxes, and the substrate fix that would have prevented
it was built the following week for a different unit. The product's diffusion
side is now *honest and nearly empty*; the goal is honest *and* complete, and
the gap is one bounded slice away.
