## 1. Intent

Every text layer must answer four independent questions from the exact
source occurrence that owns it: (1) which computation occupies the layer slot;
(2) which attention mask is created and applied; (3) which positional
operation is actually applied, and where; (4) which optional per-layer
modules exist (MoE, cross-attention, MTP, per-layer embeddings, codebook
streams). "Config supplies values and selector operands. It never supplies
mechanism meaning by field presence, token spelling, frequency convention or
model identity. A mixed stack remains mixed. An unproved layer remains
unknown; it does not borrow the majority layer's architecture."

Binding laws: occurrence before interpretation; one selector proof, many
mechanisms; syntax is not semantics (no YAML `local`→sliding); **positive
facts and complete negatives** ("absence needs a complete candidate census for
that layer"); geometry follows mechanism; independent axes never vote for one
another; embedded equals standalone. Scoped out: diffusion position (U10),
modality fusion / K-V source semantics (U9).

every semantic table deleted, 58 debt rows retired, shadow-first with one
