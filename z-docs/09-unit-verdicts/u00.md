# U0 — Freeze the real baseline

## 1. Intent
Master plan §20.3: a whole-tree fingerprint ("`git diff` alone omits untracked
files"), every witness saved on seven surfaces *without re-blessing*, run the
gate alone → grouped → full → sable-alone, and a mutation test proving the
fingerprint gate rejects a tampered tree. No production behaviour change. The
commit also pinned the §5 audit findings as 12 strict-xfail probes P1–P13.

## 2. What landed (verified)
`e3e8b85` added `test_support/tree_state.py`, `tests/test_isolation.py`,
`tests/test_authority_probes.py`, `tests/preservation_manifest.json` (sha256 of
25×7 *local, gitignored* artifacts). **No test consumed the manifest**; the
corpus inputs were not even tracked (first tracked at `602dcb0`). U0 became
real only through the recovery chain: REC-1 (`a14341b`, canonical surfaces
from production APIs, `<MOUNT>` normalisation, 8-case poison matrix), REC-7
(`cc5e328`, blocking live comparison — but still skip-on-missing-baseline),
COR-0 (`602dcb0`, corpus committed, `preservation_expected_manifest.json`,
`verify_against_expected` with no skip path, clean-checkout `git archive`
reproduction). Today: 29 witnesses, zero skip/xfail in `test_preservation.py`,
six unconditional isolation tests. The original digest file is still tracked
but dead. Probes P9 and P10 remain `xfail(strict=True)` at HEAD.

## 3. Why things happened
The §21 row claimed "BLOCKING GREEN — 25/25 frozen ×7 surfaces, 0 failures"
while nothing compared anything: hashes were of local gitignored files, HTML
hashes were raw (mount-UUID nondeterministic), no verifier existed. Detection
was accidental — an independent comparison found U1 had changed 15/25
diffusion IRs undetected. Two recovery rounds were needed because REC-7 fixed
"blocking" but not "reproducible". The superseding tracker row records the
over-claim honestly.
