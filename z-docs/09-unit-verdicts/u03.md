import aliases, classes and bases, constructed submodule references,

exact owner; unions become rival/ambiguous; bare `None` becomes a closed

owner graph and cannot disagree because they scanned different files, classes
or closures."*

"External import closure is EXPLICIT: shared diffusers files enter as

result is `partial`), open-world local relations only, "U3 done ≠ correct
renders." The ratified amendment (2026-07-27) closed U3 with a *non-growing
legacy quarantine* rather than full reader migration.

## 3. Why things happened

- **B1 V1→V4.** The first model-stage chooser used execution semantics
  ("primary sequence body") and was rejected as classification; V2 replaced it
  with the closed `FrameworkAddressProtocol` and lazy exact precedence
  (root-direct → exactly-bound base → C3 only when fully indexed; an
  unresolved base is `failed(mro_incomplete)`, never skipped). Corpus: 10
  resolved / **15 `mro_incomplete`** / 1 absent. The 15 are *every diffusion
  root* — their bases (`ModelMixin`, `ConfigMixin`) live in files the bundle
  never contains. **The bundle boundary surfaced on day three.** The chosen
  answer was "diffusion root is adapter-*authorized*, never inferred from B1
  failure" — routing around the gap instead of indexing the closure.
- **B2 V2→V4.** Added the `index_mismatch` law: an index holding the wrapper
  file but omitting the child file must not masquerade as `absent`. Again a
  partial-bundle symptom handled as a typed failure rather than a widened
  bundle.
- **Execution substrate (~6 rounds).** Each round removed a completeness
  claim (`coverage='closed'`, `resolved`, "unordered"); alias/transform/
  ambiguous producers preserved as typed state. Correct and general.
- **Semantic-delta adjudication.** Neutral U3 proven byte-identical across 26
  witnesses via a detached-worktree harness (after discarding a first harness
  that imported the live checkout — a real methodology fix). Nine
  `RMSNorm → Norm` views on T5/UMT5 towers approved by Soumil 2026-07-28 and
  re-blessed (`6676999`) with `superseded_hash_signature` retained.
- **The DeepSeek/GLM episode.** The exact ordinary-FFN reader refused to
  choose between two guarded `self.mlp` construction sites (dense vs MoE) and
  the adjudication *accepted* the generic result as "honest removal of
  unsupported specificity." The re-vet (`4bd1395`) found the source fully
  specific; the fix (`ffn_mechanism.py::_conditional_ffn_alternatives` —
  unanimous-across-exhaustive-alternatives) is general, with GPT-OSS as the
  routed-only negative. **The lesson was institutionalised only as prose**
  (§7 "mandatory lost-detail procedure"); `grep -rli lost.detail` over
  `tests/ scripts/ model_unfolder/` finds nothing but fixture JSON. Nothing
  compares a candidate's specificity against the blessed baseline.

## 6. Overlooked / unassigned

1. **Import closure was declared, scaffolded, then quarantined instead of
   promoted.** `_augment_diffusion_files` — a general, bounded, called-names-only
   import follower, i.e. exactly what boundary 8 asked for — was filed as a
   U14 "conformance-local" legacy site. Every diffusion root then failed B1,
   the diffusor parser kept a second source universe, and U10's index saw
   only the root file. U11-A is the boundary-8 deliverable, built five weeks
   after U3 closed.
2. **No recall gate.** Every U3 gate is precision-shaped. `superseded_hash_signature`
   records a change but cannot tell a relabel from a collapse to unresolved.
3. Two early boundary symptoms (B1's 15 `mro_incomplete`, B2's
   `index_mismatch`) were typed away rather than escalated as "the closure is
   not in the bundle."
4. Tracker drift between the master row and the closing tree; the z-docs
   mirror of the runbook is 457 vs 701 lines and predates the correction.
5. Manual weight tying was migrated with no inventory row, so it is invisible
   to the ratchet (migrated reader with no consumer-side proof obligation).

## 7. Verdict

**Grade: B−.** The kernel is A-grade — content-addressed index,
occurrence-exact ownership, closed reader outcomes, honest open execution
flow, a working quarantine ratchet, and the strongest receipt discipline in
the campaign; the DeepSeek/GLM re-proof is a general mechanism, not a patch.
But the goal's own words — readers must not disagree "because they scanned
different **files … closures**" — name the failure: U3 defined the index
boundary, wrote the rule for crossing it, built the parameter, and closed with
the model's own file as the universe. It institutionalised precision without
recall, and the lost-detail lesson only as text. U10's blank boxes are the
predictable downstream of both.
